## PR #26 — 진입 다양화 + 용어 설명 상한

`#123` 실측: claim 조합은 43건에 28가지로 다양한데 **첫 문장은 전건이
`<종목> + 등락률` 한 형태**였다.

원인은 `select` 가 `CLAIM_SPECS` 순서로 돌려주는 것이다. `change`·`close` 가
스펙 앞쪽이라 블록 맨 위에 늘 먼저 오고, 모델은 블록 순서대로 쓴다. 앵글이

고른 순서(앵커 + 앵글 우선분)대로 돌려주고 블록에 진입점을 명시한다.
캐시 199건 재현: 진입 사실 **1종 → 8종**.

|---|---|
| duration | `ret5` 110 |
| compare·ratio·amount | `vol_ratio` 93 |
| reaction | `vol_ratio` 74 · `change` 50 · `range` 40 · `gap` 26 |

프롬프트 지시를 늘린 것이 아니라 이미 있는 선정에 순서를 준 것이다.

### 용어 설명 반복 상한

`#124` 실측: 리서치 10건 중 9건에 `적정가격은 증권사가 …` 가 그대로 들어갔다.

## PR #27 — 리포트 요지 사실화

`#124` 리서치 10건이 fit 전건 1~2점, 총점 10.0~11.3. 심사 사유는 전건
`제목만 반복, 근거 내용 부재`. facts 가 제목·목표가·투자의견 셋뿐이라
구조적으로 이 점수대다.

프로브 실측(2026-09-16, `data/research_probe.txt`): front-api `content` 는
**273~586자 애널리스트 요약문**이고 정형 실적 수치가 있는 것은 5건 중 1건뿐.
'수치만 더 뽑기' 로는 밀도가 안 는다.

그래서 요지를 사실로 넘긴다. **사용자 컴플라이언스 확인 완료.**
종전 주석 `본문 자체는 리포트 저작물이라 저장하지 않는다` 를 대체했고,
변경 경위를 `research.py` docstring 에 남겼다.

원문을 그대로 싣지 않는 구조로 넣었다.

| 장치 | 내용 |
|---|---|
| `_gist()` | 문장 경계로 자르고 `GIST_MAX` 180자 상한 |
| 중복 제거 | 목표가·투자의견을 말하는 문장은 이미 별도 사실이라 건너뛴다 |
| 출처 표기 | 발간 증권사 표기가 이미 의무 |
| **재작성 강제** | 원문이 문어체라 그대로 베끼면 `literary_style`·`어미단조` 에 걸린다 |

마지막이 핵심이다. 감사 I2 의 WARN 2건이 정확히 이것이고, **이 경우엔
의도된 동작**이다 — 원문 복제 경로가 필터로 막혀 있다는 증거다.
WARN 이 사라지면 오히려 복제 경로가 열린 것이니 확인해야 한다.

앵커에 순서를 줬다. `keep = picked[:n]` 이라 앞쪽이 낮은 cap 에서도 살아남는다.

```
ANCHOR_TYPES["research"] = ["gist", "target", "opinion"]
```

목표가가 앞이면 모든 리포트 글이 `적정가격 X원` 한 형태로 수렴한다.
요지가 없는 경로(한경)에서는 `target`·`opinion` 이 자동으로 앞으로 당겨진다.

**버그 발견**: `policy` 주장 패턴이 `리포트 요지:` 까지 잡아 리서치 글에
정책 주장이 섞였다. 줄 시작으로 한정했다 (`(?m)^요지:`).

## PR #28 — 소수점에서 끊기던 문장 규칙

`#122` 실발송분에서 필터가 놓친 2건. **원인이 같았다** — `[^.!?\n]` 만 쓰면
`5.0%` 의 소수점에서 끊겨 뒤의 어미에 닿지 못한다.

```
이오테크닉스가 장중 고저 차이는 저가 대비 5.0%였네요   ← 이중 주어 비문
제주반도체가 장중 저가 대비 5.9% 범위로 움직였습니다    ← 금지 표현
```

소수점을 숫자 사이에서만 허용하고(`(?:[^.!?\n]|\d\.\d){0,30}`), 라벨 표기와
어미를 넓혔다. `범위로 움직` 은 조사를 열거하지 않고 받는다.

등락률·비율이 대부분 소수라 **이 계열 규칙 전반이 같은 구멍을 가질 수 있다.**
다른 규칙도 한 번 훑어볼 가치가 있다.

오탐 확인: `#124` 실발송 50건 전건 통과.
