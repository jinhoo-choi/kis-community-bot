# 시가 시작 표현 비교기준 오탐 수정

## 기준과 실측 근거

- 시작점: `main` `0bfde5284c8575ee3fe24c0f440da603de30a3ab`
- 자연 실행: [37537764333](https://github.com/jinhoo-choi/kis-community-bot/actions/runs/37537764333),
  실제 실행 코드 `0162ce578ceb332d584bf13dda965b32e0e2f8c3` (PR #65 반영, #66 미반영)
- [검증 artifact 11446804979](https://github.com/jinhoo-choi/kis-community-bot/actions/runs/37537764333/artifacts/11446804979):
  필터 기록 214행 중 비교기준 리젝 1건, 날짜불일치 0건. 실제 발송은 고유 50건이다.
- 원문: 결과 커밋 `0bfde52`의 `data/market_cache.json`, `flow-2026-10-06-192250`
- 리젝 본문·사유: 같은 커밋의 `data/run_log.txt:142–143`

원문은 `시가 출발: 전일 종가 대비 8.2% 높게`다. 본문은 다음과 같다.

> 케이사인이 13.45% 올랐습니다. 전일 종가 대비 8.2% 높게 시작한 뒤 종가는 9,530원으로 마감했네요. 장중 고가 대비 8.0% 낮은 수준이었고, 등락 크기는 최근 20거래일 평균 등락폭의 5.4배였습니다. 거래량은 20일 평균의 25배!

기존 `_BASIS`는 시가 출발에 `시가|출발`만 허용해서 이 글에
`근거없는수치['25'],비교기준누락(8.2%)`를 반환했다. 비교기준 사유만 오탐이다.
거래량 원문은 `17.6배`이므로 전체 글을 승인해서는 안 된다.

## 변경과 불변식

| 변경 | 유지할 불변식 |
|---|---|
| `src/filters.py`의 좁은 시가 시작 표현 인정 | facts의 `시가 출발`에 명시된 전일 종가 기준, 같은 퍼센트와 높게/낮게 방향을 모두 대조한다 |
| 각 숫자 바로 앞의 `전일 종가 대비`와 뒤의 `높게/낮게 시작한 뒤` 또는 한정된 `시작했습니다/했네요/했어요/했다` 검사 | 다른 숫자·다른 문장의 기준이나 일반적인 `시작` 단어를 빌려 통과하지 않는다 |
| 고정 사례 2건과 오프라인 비교기준 회귀 추가, `run_tests.sh` 연결 | 기존 비교기준·귀속·날짜·숫자·주장 상한을 변경하지 않는다 |
| 기존 LIG 실측 테스트의 입력 고정 | `posts_latest.json` 교체로 과거 사례가 사라져도 기존 누락 리젝을 계속 검증한다 |

전체 본문은 수정 후에도 `근거없는수치['25']`로 차단된다.
`25배`만 `17.6배`로 고치면 `주장과다(6개/5)`가 남는다. 해당 거래량 문장을
제외한 근거 있는 5개 주장 본문은 통과한다. 주장·수치·게이트 코드는 건드리지 않았다.

## 기존 테스트 실패와 PR #66 관계

코드 수정 전 전체 검사에서 단위 474/474, 문장틀 14/14 다음
`tests/test_cost_offline.py:298`의 `StopIteration`으로 중단됐다. 정기 실행이
`posts_latest.json`을 교체해 `flow-2026-10-02-079550`이 없어진 원인이다.
해당 본문·facts·검사 인자만 `0162ce5:data/posts_latest.json`에서 고정 fixture로 옮겼다.
현재 발송분·문장틀 오탐 검사도 유지하며, 알려진 과거 LIG 사례가 포함된 경우만
그 1건의 리젝을 기대한다. 새 테스트는 롤링 데이터에 의존하지 않는다.

#66도 `tests/test_cost_offline.py`를 수정하지만 배치 fake client와 SDK 회귀 부분이다.
이 PR은 기존 비교기준 회귀의 fixture 부분만 수정한다. #66 패치를 이 작업 위에
`git apply --check`한 결과 hunk 충돌이 없다. 배치 코드와 SDK 동작은 변경하지 않았다.
