# 2026-10-13 정책 RSS 종료 대응

기준 커밋: `4805c72b281e77e4ff6d8941c5bb193412549757`. 이 문서와 변경 코드·테스트는 같은 PR에 있다.

## 문제와 실측

10/13 정규 실행 `38314114264`는 korea.kr 직접 RSS 4곳에서 404를 기록했다. IP 제한만으로 단정했던 기존 소스 설명을 정정한다. 정책브리핑은 [공식 공지](https://www.korea.kr/etc/noticeView.do?newsId=132038885)에 따라 2026-07-01 RSS 제공을 종료했다.

재정경제부 [공식 RSS 안내](https://mofe.go.kr/mn/siteguide/rssService.do?menuNo=2060000)의 보도·참고자료 피드는 HTTP 200, RSS item 40개였다. `description` 없이 제목·link·`pubDate`만 제공한다. 상세 HTML의 `input#nttCn` 요약 필드를 실제 확인했다. 수정 수집기로 원문 40개 중 시각 제외 33개, 요지 미확인 5개, 최신 요지 확인 2개를 수집했다. 이는 수집 후보이며 생성·심사·배포 완료 건수가 아니다.

금융위 공식 RSS·상세 목록은 이번 환경에서 503, 산업부 RSS는 GET 405/공식 폼 POST 503이었다. 이를 정상 복구했다고 보고하지 않는다. 이 두 기관은 공식 도메인을 대상으로 한 검색 RSS로 보완한다. 검색 결과는 원문 직접 확인을 대신하지 않는다.

## 변경과 불변식

| 변경 | 불변식 |
|---|---|
| 종료된 korea.kr/rss/* 네 주소 제거 | 기존 정책브리핑 검색 RSS와 연합뉴스 두 피드 유지 |
| 재정경제부 공식 RSS를 먼저 확인 | 전체 반환 상한 유지, 공식 후보 최대4개로 뉴스 공간 보존 |
| 메타만 있는 공식 자료는 HTTPS 상세 요약 확인 | 회차당 추가 HTTP 최대4회·각12초, PDF/첨부·LLM 사용 없음 |
| 공식 상세 URL 허용 목록과 실제 `nttCn` 필드 사용 | 다른 호스트·게시판·불명확한 식별자 제외, 본문 없으면 추정하지 않음 |
| 실제 발행기관 `재정경제부`를 기관 앵커에 추가 | 기존 날짜 48시간/월요일72시간·제외어·정당/인물/기업 사건 규칙 유지 |
| 공식/뉴스/검색 수집량과 요지 미확인 수를 구분 | HTML 오류를 정상 RSS나 소재로 세지 않음, 출처·발행시각 보존 |

공식 보도자료와 언론·검색 자료의 주의 문구를 구분한다. 생성·심사·배포 게이트와 50건 목표, 비용 기준, 모델·페르소나·일정·텔레그램 설정은 변경하지 않았다. 짧은 공식 요지는 기존 소재 게이트에서 계속 보류될 수 있다.

## 검증

- 새 RSS 회귀 12개 통과: 실제 XML 형태, 요지 조회, 요지 없음·오래된/무날짜·무관 제목 제외, 외부/잘못된 링크, HTTP 예산, HTML 오류, 뉴스 폴백, 전체 상한, 종료 주소 미호출, 0건 상한.
- Python 3.11 구문, YAML, 변경 파일 pyflakes 통과.
- 기존 회귀: unit474/474, template14/14, cost43/43, mocked pipeline9/9, E2E20/20 통과.
- 수정 전·후 전체 `run_tests.sh` 모두 동일한 기존 감사 실패2/경고2. 공시 캐시의 `분할 방법`·`분할 목적` 줄에 남은 상법 `제530조`/`제12` 숫자를 I1이 탐지했다. 새 RSS 회귀 실패는0. 감사의 차단 조건을 약화하거나 캐시를 삭제해 통과시키지 않았다.

따라서 전체 CI 통과로 보고하지 않으며, 기존 감사 문제와 교차 검토가 해결되기 전 병합하지 않는다. 실메일·텔레그램·유료 모델·수동 운영 워크플로 실행 없음.
