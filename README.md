# KIS Community Post Bot

> **AI가 작업을 시작하기 전에 읽을 것**
> - [`docs/STATE.md`](docs/STATE.md) — 지금 무엇이 깨져 있는지
> - [`docs/AI_COLLABORATION.md`](docs/AI_COLLABORATION.md) — 역할 분담과 상호 검토 규칙

한국투자증권 앱 커뮤니티 활성화를 위한 **AI 게시글 생성·배포 파이프라인**.
전일자 공시/리포트/수급/정책을 수집해 하루 50건의 게시글 초안을 만들고,
텔레그램으로 직원에게 배포한다. **게시는 사람이 직접 하며, 게시글에는 'AI 작성' 뱃지를 부착한다.**

## 흐름 (멀티 LLM)
```
수집 → 필요한 항목만 사실 보강 → 하드 게이트 → 종목·게시판 매핑 → 중복제거
  → [1] 단계별 작성 : 유형을 섞어 100건씩 Claude + Gemini 호출
  → [2] 결정형 검수 : 근거 수치·derived fact·문체 계약 확인
  → [3] 교차 심사   : 작성자와 다른 모델이 6축 채점
  → [4] 배포 판정   : 점수 / fit / 종목·유형·문체 상한
  → 목표 달성 시 중단 → 텔레그램 성공분만 상태·통계 저장
```

## 설계 원칙
| 원칙 | 구현 |
|---|---|
| **구조적 규칙 > AI 판단** | `src/gate.py` — 상폐·횡령·이해상충 종목은 AI 호출 **이전**에 배제 |
| **미탐 > 오탐** | 애매하면 배포하지 않는다. 리스크 모니터링과 반대 방향이므로 bypass 규칙 없음 |
| **규칙 단일 소스** | `src/rules.py` → 작성 프롬프트 / 심사 프롬프트 / 정규식 3곳에 파생. 이중 관리 금지 |
| **판정 로직 분리** | `src/decide.py` 순수 함수. 테스트가 프로덕션 코드를 직접 호출 |
| **모델 은퇴 대비** | candidate list + 404/deprecated 감지 시 자동 폴백, `run_stats.jsonl` 기록 |
| **근거 있는 보강만 사용** | 검색 grounding URL이 있는 결과만 보강하고, 호출 오류는 캐시하지 않음 |
| **전송 확인 후 상태 저장** | 텔레그램 성공 응답을 받은 글만 `seen`과 발송 통계에 반영 |

## 하드 게이트 tier (`src/gate.py`)
| tier | 배제 대상 |
|---|---|
| 1 | 상장폐지·관리종목·거래정지·횡령·배임·분식·검찰·제재 |
| 2 | **이해상충** — 한국금융지주 등 자사 계열 |
| 3 | 정치테마·투자경고·단기과열 |
| 4 | 주총소집 등 정보량 없는 형식 공시·제목 부족 |

## 크롤링 방어 (`src/crawl.py`)
| 방어 | 이유 |
|---|---|
| 셀렉터 배열 폴백 | 단일 셀렉터는 사이트 개편 당일부터 **조용히 0건** |
| 실패 시 타임아웃 늘려 1회 재시도 | 일시적 지연이 수집 실패로 새는 것 방지 |
| 랜덤 지연 | 고정 간격은 봇 탐지 신호 |
| **헬스체크** | 0건 또는 기대치 30% 미만이면 텔레그램 운영 경고. 예외보다 조용한 0건이 위험 |

### E2E 시나리오
| ID | 재현하는 상황 |
|---|---|
| S2 | 횡령·자사계열·정정공시·정치테마 유입 → 하드 게이트 |
| S3 | 모호명 단독(`대상`) / 부수언급(밸류체인 협력사) → 귀속 강등 |
| S4 | 같은 사건이 DART·리서치로 동시 유입 → 다축 dedup |
| S5 | 1인칭·매매권유·목표가·환각수치 생성물 → 정규식 + 교차심사 |
| S6 | 한 종목 5건 몰림 → 종목 상한 |
| S7 | 크롤링 조용한 0건 → 운영 경고 |
| S8 | 모델 은퇴(404) → 자동 폴백 |
| S9 | enrich 실패 → thin_facts 프롬프트 주입 |
| S10 | 두 프로바이더 분산 + 교차 심사 |

### 왜 두 모델을 쓰는가
| 단계 | 담당 | 이유 |
|---|---|---|
| 사실 보강 | Gemini (grounding) | 검색 그라운딩으로 배경 사실을 채워 환각과 공허한 글을 동시에 줄임 |
| 작성 | Claude + Gemini 8:2 | 실측 품질을 반영하되 보조 provider와 폴백 경로를 유지 |
| 심사 | 교차 (작성자 ≠ 심사자) | 같은 모델이 자기 글을 채점하면 점수가 후해진다(self-preference bias) |
| 재생성 | 다른 프로바이더 | 같은 모델은 같은 실수를 반복함 |

심사는 factual / useful / natural / compliant / gain / fit 각 5점이며 20점으로 환산합니다.
치명적 위반(환각 수치·매매권유·1인칭 거래경험)은 점수와 무관하게 즉시 탈락.

## 문체
10개 통합 페르소나와 11개 Angle을 조합합니다. 각 페르소나가 문장 수·길이·숫자·
질문 여부를 함께 소유해 축 간 모순을 줄입니다. 1인칭 투자 경험 서술은 자동 리젝됩니다.

## 세팅
1. `pip install -r requirements.txt`
2. GitHub Secrets 등록: `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `DART_API_KEY`, `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`
   - 한쪽 키만 넣어도 동작한다. 살아있는 프로바이더에 물량이 자동으로 몰린다.
3. 로컬 점검: `python main.py --dry-run` (LLM·텔레그램 호출 없이 소스 수집·게이트 확인)
4. 테스트: `./run_tests.sh`
5. 스케줄: `.github/workflows/daily.yml` — UTC 21:11 = KST 06:11

## 자동 검수 (src/filters.py)
매매권유 / 목표가단정 / 1인칭경험 / 단정예측 / 마크다운·이모지 / 길이 /
**원문에 없는 숫자(환각)** → 리젝 후 1회 재생성

## 주의
- 리포트 원문(PDF)은 저장·재배포하지 않는다. 제목·메타 + 원문 링크만 사용.
- AI 작성·출처·투자책임 고지는 앱 게시 단계에서 자동 부착하며 텔레그램 복사 본문에는 넣지 않는다.
- 운영 전 준법감시 템플릿 사전승인 권장.
